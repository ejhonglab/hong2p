Utility functions for working with pandas objects (DataFrames, Series, and their indices)

hong2p.pandas.addlevel(data, names, values, *, axis='index')[source]

Add level(s) to pandas MultiIndex. Does not change input.

Intended to be an inverse to pandas.DataFrame.droplevel. pandas.DataFrame.set_index with append=True would work except that there is no axis kwarg to that function, so it does not work for the columns. pandas.DataFrame.unstack is almost what I would want, but it can seemingly arbitrarily change order of rows.

Parameters:

  • data (DataFrame | Series) – DataFrame/Series to add MultiIndex levels to

  • names (str | List[str]) – str/sequence-of-str name(s) for the new levels

  • values – values for the new levels. If names is a sequence, this should be of the same length.

  • axis (Literal['columns', 'index', 'rows', 0, 1]) – 0/’index’ or 1/’columns’, defauling to ‘index’ as in pandas

Return type:

DataFrame | Series

Returns: DataFrame with MultiIndex containing names/levels from input

hong2p.pandas.expand_array_cols(df)[source]

Expands any list/array entries, with new rows for each entry.

For any columns in df that have all list/array elements (at each row), the column in out_df will have the type of single elements from those arrays.

The length of out_df will be the length of the input df, multiplied by the length (should be common in each input row) of each set of list/array elements.

Other columns have their values duplicated, to match the lengths of the expanded array values. Columns are in the same order as in df.

Args: df (pd.DataFrame)

Returns: out_df (pd.DataFrame)

hong2p.pandas.invert_melt_symmetric(ser, suffixes=('_a', '_b'))[source]

Takes Series (as output by melt_symmetric) back to a square DataFrame.

Levels ending in first suffix (that have a matching level ending in the second suffix) are unstacked into columns. Levels without such a pair are dropped. Only values in ser are filled, so output will have NaN in other triangle, if ser only has one triangle (as by default in melt_symmetric).

hong2p.pandas.melt_symmetric(symmetric_df, drop_constant_levels=True, suffixes=('_a', '_b'), name=None, keep_duplicate_values=False)[source]

Takes a symmetric DataFrame to a tidy Series with unique values.

Symmetric means the row and columns indices are equal, and values should be a symmetric matrix.

Output index has levels from both row and column indices, suffixed with suffixes (unless they already were).

Parameters:

  • symmetric_df – data to melt. rows/columns that are all NaN are dropped.

  • drop_constant_levels – if True, drops (MultiIndex) levels with only one value

  • suffixes – added to row and column index level names, respectively

  • name – name of output Series

  • keep_duplicate_values – if False, only upper triangle (including diagonal) is kept. otherwise, all values are kept.

See invert_melt_symmetric for inverse.

hong2p.pandas.pd_allclose(a, b, *, if_index_mismatch=None, **kwargs)[source]

Like np.allclose, but also checks pandas indices are equal.

Scalars and numpy arrays are also supported (compared with np.isclose / np.allclose). str/object columns of DataFrames are compared for exact equality.

Parameters:

  • a|b – inputs to compare. must both be either DataFrames or Series.

  • if_index_mismatch (str | None) – passed to pd_indices_equal

  • **kwargs – passed thru to np.allclose (equal_nan=True may be the most useful)

Return type:

bool

hong2p.pandas.pd_index_equal(a, b, *, axis='index', only_check_shared_levels=False, assert_no_dupes_in_shared_levels=True, if_index_mismatch=None)[source]

Returns whether a and b have equal indices along axis.

Parameters:

  • a|b – DataFrames / Series to compare indices of

  • axis (str) – ‘index’ or ‘columns’

  • only_check_shared_levels (bool) – if True, will only check level names shared between both indices, but requires that they share at least one level. see assert_no_dupes_in_shared_levels.

  • assert_no_dupes_in_shared_levels (bool) – if True, will assert shared levels do not have duplicates in either input index (so that they could be a valid index on their own, otherwise, the equality may not mean as much). only relevant if only_check_shared_levels=True

  • if_index_mismatch (str | None) – None (just return False), ‘warn’ (warn and return False), or ‘err’ (raise ValueError) if indices do not match

Return type:

bool
