hong2p.suite2p.invert_combined_view_offset(combined_ops, roi)[source]

Returns copy of roi w/ coords shifted from suite2p combined view to its plane.

In the suite2p “combined” view, planes are tiled in a grid. This subtracts the offset of the tile the ROI is in (roi[‘iplane’]) from the ‘xpix’, ‘ypix’, and ‘med’ coordinates.

Parameters:

  • combined_ops – suite2p ops from the ‘combined’ output directory

  • roi – a single suite2p ROI “stat” dict (from ‘combined’ outputs)

hong2p.suite2p.load_s2p_outputs(plane_or_combined_dir, good_only=True, merge_inputs=False, merge_outputs=False, subset_stat=True, err=False)[source]

Returns suite2p outputs, with traces as a DataFrame

Loads outputs from plane_or_combined_dir, tossing data for ROIs marked “not a cell” and ROIs merged to create others (by default).

Parameters:

  • plane_or_combined_dir (str | Path) – directory containing suite2p outputs

  • good_only – whether to drop data for ROIs marked “not a cell” in suite2p GUI

  • merge_inputs – whether to drop data for ROIs merged to create other ROIs

  • merge_outputs – whether to drop data for ROIs created via merging in suite2p

  • subset_stat – whether to also drop data in returned stat_dict according to the above criteria.

  • err – whether to raise errors about ROI “cell / not cell” labels if good_only

Returns:

DataFrame w/ ROI numbers and extracted signals stat_dict: dict of ROI num -> suite2ps “stat” ROI data ops: suite2p options merges: dict of ROI nums of ROIs created via merging pointing to a list of the

ROI nums merged to create them. can be used for implementing your own merging strategies.

Return type:

traces

Raises:

  • IOError – if suite2p outputs did not exist

  • LabelsNotModifiedError – if err and good_only and the “cell / not cell” labels have not been modified.

  • LabelsNotSelectiveError – if err and good_only and no ROIs were marked “not a cell” in suite2p (assumes that some noise ROIs would have been pulled out). This can be caused by setting the threshold to 0 and not modifying the ROIs further manually.

hong2p.suite2p.remerge_suite2p_merged(traces, stat_dict, ops, merges, response_stats=None, how='best_plane', renumber=False, verbose=False)[source]

Drops all but the “best” input ROI for each suite2p merge output ROI.

Accepts input as the output of load_s2p_outputs (which should have been called with merge_inputs=True).

Parameters:

  • traces – DataFrame (frames X ROIs), as returned by load_s2p_outputs

  • stat_dict – dict of ROI num -> suite2p ROI “stat” dict, as returned by load_s2p_outputs

  • ops – suite2p ops, as returned by load_s2p_outputs

  • merges – dict of merge output ROI num -> list of merge input ROI nums, as returned by load_s2p_outputs

  • response_stats – Series (indexed by ROI num) of statistic used to pick best input ROI (max value picked) for each merge output. defaults to range (max - min) of each trace.

  • how – strategy to pick input ROI(s) to keep. only ‘best_plane’ supported.

  • renumber – not currently supported

  • verbose – if True, prints which input ROIs are kept / dropped for each merge

Returns:

input traces, w/ non-best merge input ROIs dropped

rois: DataArray of ROIs (from suite2p_stat2rois), w/ the same ROIs dropped,

and roi coordinate set to suite2p ROI nums

Return type:

traces

hong2p.suite2p.suite2p_roi_stat2roi(roi_stat, ops, xy_only=False, fillna_0=True, invert_combined=True)[source]

Takes a single suite2p ROI to a dense numpy representation

roi_stat and ops are both assumed to come from the ‘combined’ folder outputs

Parameters:

  • roi_stat – a single suite2p ROI “stat” dict

  • ops – suite2p ops

  • xy_only – if True, returns 2D (y, x) array. otherwise, returns 3D (z, y, x) array, with ROI only in plane roi_stat[‘iplane’].

  • fillna_0 – if False, pixels outside ROI will be NaN rather than 0

  • invert_combined – if True, coordinates are converted from those of suite2p combined view to those within a single plane (see invert_combined_view_offset)

hong2p.suite2p.suite2p_stat2rois(stat, ops, merges=None, as_xarray=True, **kwargs)[source]

Takes suite2p ‘stat’ array / dict (roi # -> roi stat) to array / xarray ROIs.

Parameters:

  • stat – dict of ROI num -> suite2p ROI “stat” dict (array input not currently supported)

  • ops – suite2p ops

  • merges – dict of merge output ROI num -> list of merge input ROI nums. if passed, the ‘s2p_roi_num’ coordinate of each merge input is replaced with the corresponding merge output ROI num. requires as_xarray=True.

  • as_xarray – if True, returns DataArray (see numpy2xarray_rois), with ‘s2p_roi_num’ and ‘roi_z’ coordinates. otherwise, returns array with ROIs stacked along last dimension.
