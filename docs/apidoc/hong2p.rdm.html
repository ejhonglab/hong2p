hong2p.rdm module

Odor-pair matrices: one value per unordered pair of odors, as a “pair Series”.

A pair Series holds a value (a distance between two odors’ responses, a correlation, the change in either under some manipulation, …) for each unordered pair of odors (or of any other items), indexed by (odor_a, odor_b) with odor_a before odor_b in a canonical order: the odors in order first, in that order, then any others sorted (order_items; with no order, all sorted). pair_list gives the pairs of a set of odors in that order, and the functions here return pair Series indexed that way (levels named PAIR_NAMES), so outputs computed from different matrices line up pair for pair.

Distances between odors are computed across units (cells, glomeruli, model KCs) from a (units x odors) matrix (pair_distances): 1 - cosine similarity, or 1 - Pearson correlation.

Relation to the other pair helpers in hong2p: pairs_from_square takes the triangle with hong2p.util.corr_triangular (in a given order, with this module’s index names), and hong2p.util.invert_corr_triangular builds its square with square_from_pairs; those two keep al_analysis’ conventions (pairs in sorted or given order named odor1 / odor2, panel levels, a diagonal value). hong2p.pandas.melt_symmetric is the tidy form of a symmetric matrix (diagonal included, any MultiIndex), for long-format tables rather than pair statistics.

Moved from the KC-remapping experiment queue (model_experiment_queue’s kcq.harness), 2026-11-12, with the 16-odor APL panel’s order made the order argument.

hong2p.rdm.density_null_similarity(mat, order=None, *, names=('odor_a', 'odor_b'))[source]

Returns the expected cosine similarity between the odor columns of a (units x odors) matrix if unit identities were shuffled independently within each odor.

The shuffle keeps each odor’s response distribution (and so its number of responders). Exact permutation expectation: E[a . b] = N mean(a) mean(b), so E[cos] = N mean(a) mean(b) / (|a| |b|); for binary columns this is sqrt(p_a p_b). Returned as a canonical pair Series of similarities (not distances).

Return type:

Series

hong2p.rdm.odor_shares(values)[source]

Returns each odor’s share of a per-pair quantity, and the variance it explains.

The shares are the least-squares fit of the additive model value(a, b) = s_a + s_b over the pairs (pair_design); the second output is the fraction of the quantity’s variance over pairs that the additive model explains (NaN for a constant quantity).

Return type:

Tuple[Series, float]

hong2p.rdm.pair_design(pairs, odors=None)[source]

Returns the additive design over odors of a set of odor pairs, and the odor order.

One row per pair, one column per odor, 1 for the pair’s two odors (so a pair’s value is modelled as the sum of its odors’ shares). odors defaults to the odors in pairs, in order of appearance.

Return type:

Tuple[ndarray, List]
