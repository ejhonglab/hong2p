hong2p.xarray module

Utility functions for working with xarray objects, primarily DataArrays

hong2p.xarray.all_coord_names(arr)[source]

Returns all coordinate variables names, excluding names containing MultiIndex

Some dims can have a MultiIndex associated with them, where there is one name in the coordinates that should equal a name in dims, but does not equal any of the names of the levels in the MultiIndex it contains. This function will exclude those outer names from the output.

Calling reset_index() on all dimensions should produce a DataArray where the coordinate variable names match those returned here.

Return type:

List[str]

hong2p.xarray.find_matching_coords(index, arr, *, warn=True)[source]

Checks whether index and arr have compatible indices, returns matching coords

Returns coords for the first dim in arr that matches index, or None if no dims match.

Parameters:

  • index (Index) – pandas index to find matching coords for (from a single dim in arr)

  • arr (DataArray) –

    DataArray that should contain a single dimension with coordinates that match index. Index levels names (and contents, currently including sort order) should all match.

    The set of levels that match must also be unique, so that they could actually be used to reindex along this dimension. Only dimensions with length matching len(index) are checked for matching.

  • warn (bool) – if True, will warn about any coords with same length but no overlapping names, as well as any level names in one index but not the other

Return type:

Any | None

hong2p.xarray.outer_product(x, y, *, squeeze=True, drop=True)[source]

Returns outer product of two DataArrays.

Output shape is the concatenation of input shapes (x.shape + y.shape).

One should be missing a name (.name == None) or both should have matching `.name`s.

Assumed that they will have non-overlapping dims, as otherwise what would be the point of an outer product.

Parameters:

  • x (DataArray) – DataArrays to multiply

  • y (DataArray) – DataArrays to multiply

  • squeeze (bool) – whether to .squeeze() inputs before multiplying

  • drop (bool) – if squeeze=True, passes this to squeeze()

Return type:

DataArray

hong2p.xarray.save_dataarray(arr, path, *, check=True, **kwargs)[source]

Writes arr to NetCDF4 at path.

Currently requires that input does not change after being passed through: reset_all_multiindex(move_all_coords_to_index(arr)), since we need to reset MultiIndex coords for saving to netCDF to work, and if we can’t assume we can move them all back to MultiIndex (when possible) on load, we wouldn’t currently know how to recreate the saved data.

Parameters:

  • check (bool) – if True, check we get exactly the input arr, if we load the saved file

  • **kwargs – passed to <DataArray>.to_netcdf. can be used to set compression, via encoding=<dict> kwarg. see xarray to_netcdf docs.

Return type:

None
