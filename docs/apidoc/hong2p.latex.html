hong2p.latex.compile_tex_to_pdf(latex_str, pdf_fname, failed_latex_msg=None, verbose=False)[source]

Compiles LaTeX source in latex_str to a PDF, saved to pdf_fname.

Files in get_latex_dir() (e.g. figureSeries.sty) are made available to the TeX build.

Parameters:

  • latex_str – full LaTeX document source

  • pdf_fname – path to save compiled PDF to

  • failed_latex_msg (str | None) – if not None, printed before re-raising any latex.LatexBuildError

  • verbose (bool) – if True, prints path the PDF is being written to

Return type:

None

hong2p.latex.make_pdf(pdf_path, fig_dir, section_names2figs, header=None, template_path='template.tex', write_latex_like_pdf=False, write_latex_for_testing=False, test_tex_path='test.tex', only_print_latex=False, print_tex_on_err=True, verbose=False)[source]

Renders figures into a PDF, one section of figures per section_names2figs key.

Parameters:

  • pdf_path – path to write output PDF to

  • fig_dir – directory figure paths are relative to (set as LaTeX graphicspath)

  • section_names2figs – dict mapping section names to lists of figure paths (str or Path, relative to fig_dir). Sections with no figures are skipped.

  • header (str | None) – if passed, rendered (verbatim) as a header on each page

  • template_path – name of Jinja2 template, relative to hong2p latex dir

  • write_latex_like_pdf (bool) – if True, also writes rendered LaTeX next to pdf_path, w/ ‘.tex’ replacing ‘.pdf’ suffix

  • write_latex_for_testing (bool) – if True, also writes rendered LaTeX to test_tex_path

  • test_tex_path – see write_latex_for_testing

  • only_print_latex (bool) – if True, prints rendered LaTeX and returns without compiling the PDF

  • print_tex_on_err (bool) – if True, prints rendered LaTeX if compilation fails

  • verbose (bool) – if True, prints rendered LaTeX and paths of files being written

Return type:

None
