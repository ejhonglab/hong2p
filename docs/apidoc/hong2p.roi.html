Matches ROIs across consecutive timepoints, by minimizing total cost.

Parameters:

  • left_centers_or_seq (list) – (length n_timepoints) list of (n_rois x 2) arrays of ROI center coordinates. elements can also be lists of ROIs (each an array of points), in which case roi_centers is used to get centers. alternatively, a single such array, with right_centers the next.

  • *right_centers – if passed, a single array of centers to match to left_centers_or_seq

  • cost_fn (callable) – takes two centers to cost of matching them. defaults to util.euclidean_dist.

  • max_cost (float) – required. matches with cost >= this are treated as unmatched.

  • show (bool) – whether to plot centers (and matches)

  • write_plots (bool) – if show=True, whether to save plots (to current directory)

  • left_name (str) – for labelling plots, when only matching two sets of centers

  • right_name (str) – see left_name

  • name_prefix (str) – for labelling plots, when matching >2 sets of centers

  • draw_on (np.ndarray) – image to plot centers on

  • title (str) – plot title

  • colors – colors for each set of centers in plots

  • connect_centers (bool) – whether to draw lines between matched centers

  • pairwise_plots (bool) – whether to also make a plot for each pair of consecutive timepoints (only if >2 timepoints)

  • pairwise_same_style (bool) – whether pairwise plots use same colors / markers as main plot

  • roi_numbers (bool) – whether to label each center w/ its index in plots

  • jitter (bool) – whether to add small random offsets to centers in plots

  • progress (bool) – whether to show progress bar. defaults to True if >=10 timepoints.

  • squeeze (bool) – if True and only two timepoints, outputs are returned for that single pair rather than as length-1 lists

  • verbose (bool) – whether to print number unmatched for exceeding max_cost

  • debug_points (dict) – timepoint index -> list of dicts describing points to print debugging info for (see output of roi_jumps)

hong2p.roi.greedy_roi_packing(match_images, ds, radii_px, thresholds=None, ns=None, exclusion_radius_frac=0.7, min_dist2neighbor_px=15, min_neighbors=3, exclusion_mask=None, draw_on=None, debug=False, draw_bboxes=True, draw_circles=True, draw_nums=True, multiscale_strategy='one_order', match_value_weights=None, radii_px_ps=None, scale_order=None, subpixel=False, _src_img_shape=None, _show_match_images=False, _show_packing_constraints=False, _show_fit=True, _initial_single_threshold=None)[source]

Greedily places circular ROIs at best template matches, avoiding overlap.

Matches are considered in order of decreasing match value (see multiscale_strategy for the order across scales), and each is accepted unless it is too close to an already accepted ROI.

Parameters:

  • match_images (np.ndarray / iterable of same) –

    2-dimensional array of match value higher means better match of that point to template.

    Shape is determined by the number of possible offsets of the template in the original image, so it is smaller than the original image in each dimension. As an example, for a 3x3 image and a 2x2 template, the template can occupy 4 possible positions in the 3x3 image, and the match image will be 2x2.

  • ds (int / iterable of same) – integer width (and height) of square template. related to radius, but differ by margin set outside.

  • radii_px (int / iterable of same) – radius of cell in pixels. if iterable of length >1, multiscale matching is used, with one element of each of match_images, ds, and radii_px per scale.

  • thresholds (float / iterable of same) – only match values above these are considered (one per scale, or the same for all). pass exactly one of this or ns.

  • ns (int / iterable of same) – if int, total number of ROIs to find (across scales). if iterable, number of ROIs to find at each scale. pass exactly one of this or thresholds.

  • exclusion_radius_frac (float) – approximately 1 - the fraction of two ROI radii that are allowed to overlap.

  • min_dist2neighbor_px (float) – see min_neighbors

  • min_neighbors (int) – ROIs without at least this many other ROI centers within min_dist2neighbor_px are dropped (after packing). falsey values disable this filtering.

  • exclusion_mask (np.ndarray) – if passed, boolean mask (of shape of original image) where ROI centers can be placed (only True pixels allowed)

  • draw_on (np.ndarray) – if passed, 2D image (of shape of original image) to draw accepted matches on (only shown if debug=True and _show_fit=True)

  • debug (bool) – whether to print and plot debugging information

  • draw_bboxes (bool) – whether to draw template bounding boxes on draw_on

  • draw_circles (bool) – whether to draw ROI circles on draw_on

  • draw_nums (bool) – whether to draw ROI numbers on draw_on

  • multiscale_strategy (str) –

    how to order matches across scales. ‘one_order’: all matches sorted together by (weighted) match value. ‘fixed_scale_order’: all matches at each scale before the next, in order of

    scale_order.

    ’random’: next scale randomly sampled, with probabilities radii_px_ps.

  • match_value_weights (iterable of float) – for ‘one_order’ strategy, factors to multiply match values of each scale by, before sorting

  • radii_px_ps (iterable of float) – for ‘random’ strategy, probability of sampling each scale (must sum to 1)

  • scale_order (iterable of int) – for ‘fixed_scale_order’ strategy, order of scale indices

  • subpixel (bool) – not implemented

Returns:

array of shape (n_rois, 2), with centers of ROIs (in coordinates of

original image)

radii: array of shape (n_rois,), with radius (in pixels) of each ROI

Return type:

centers

Takes a list of n_cells x 2 matrices, with each row taking an integer ROI label from one set of labels to the other.

Input is as first output of correspond_rois.

Returns: stable_cells: a n_stable_cells x (len(lr_matches) + 1) matrix, where rows

represent different labels for the same real cells. Columns have the set of stable cells IDs, labelled as the inputs are.

hong2p.roi.template_match(scene, template, method_str='cv2.TM_CCOEFF', hist=False, debug=False)[source]

Returns image of template match values (higher is better), at each offset.

Both scene and template are converted to uint8 (via util.baselined_normed_u8) before matching with cv2.matchTemplate. Output is negated for SQDIFF methods, so that higher is always better.

Parameters:

  • scene – 2D image to search for template in

  • template – 2D template image

  • method_str – str that evaluates to a cv2.TM_* matching method

  • hist – if True, plots histogram of match values

  • debug – if True, prints / plots information about scaling of inputs (and sets hist=True)
