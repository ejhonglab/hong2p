hong2p.chem.chemfig_standalone_tex(chemfig_tex, *, atom_fontsize='\\tiny', chemfig_opts='atom sep=1.0em,bond offset=1pt,double bond sep=4pt,bond style={line width=0.8 pt}', border='2mm')[source]

Returns TeX for a standalone document rendering chemfig_tex.

Parameters:

  • chemfig_tex (str) – TeX for a single chemfig{…} command (e.g. from cid2chemfig_tex)

  • atom_fontsize (str) – TeX font size command used for atom labels

  • chemfig_opts (str) – passed to setchemfig

  • border (str) – border for standalone document class

Return type:

str

hong2p.chem.cid2chemfig_tex(cid, *args, ignore_cache=False)[source]

Returns chemfig TeX for PubChem cid, generated by mol2chemfig (or cache).

Parameters:

  • cid (int) – int PubChem CID

  • ignore_cache (bool) – if True, ignore values in chemfig_cache (but will still update it with new values)

  • *args – passed to mol2chemfig, in addition to default –hydrogens delete this function adds. if any are passed, cache is neither read nor updated (since it is only keyed by CID).

Return type:

str

NOTE: in addition to having chemfig installed, also need mol2chemfig.sty copied into overleaf project, and then usepackage{mol2chemfig} in addition to usepackage{chemfig}, despite it being on CTAN.

Can copy from CTAN or I may commit into my thesis repo once I make that.

hong2p.chem.draw_molecule(cid, output_name=None, output_dir=None, *, chemfig_output_dir=None, ignore_cache=False, verbose=False, **kwargs)[source]

Renders 2D structure of PubChem cid to a PDF, via chemfig + LaTeX.

Parameters:

  • cid (int) – PubChem CID

  • output_name (str | None) – basename (w/o extension) for output .tex/.pdf files. defaults to str(cid).

  • output_dir (Path | None) – directory to write standalone .tex and compiled PDF to. defaults to current directory.

  • chemfig_output_dir (Path | None) – if None, also writes just the chemfig TeX to <output_dir>/chemfig/<output_name>.tex. if passed, the chemfig TeX is currently not written anywhere.

  • ignore_cache (bool) – passed to cid2chemfig_tex

  • verbose (bool) – if True, prints generated TeX and paths of files being written

  • **kwargs – passed to chemfig_standalone_tex

Return type:

None
