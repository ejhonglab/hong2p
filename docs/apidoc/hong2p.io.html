hong2p.io module

Writing analysis outputs (CSVs, parquet, pickles, JSON, figures), and reading them back.

Paths written via functions wrapped with produces_output (e.g. to_csv) and via savefig are recorded for the rest of the process, and writing the same path twice raises MultipleSavesPerRunException (usually a mistake). With check_outputs_unchanged set (e.g. by the -c flag added by add_check_outputs_unchanged_CLI_flag_and_parse_args), an existing output is compared to what would replace it, raising an error if it would change.

Settings are module attributes, read when the functions are called (e.g. set hong2p.io.verbose = True on the module, not on a name imported from it): verbose, check_outputs_unchanged, prompt_if_changed, ignore_existing (see should_ignore_existing), save_figs, plot_fmt and exit_after_saving_fig_containing (see savefig).

hong2p.io.produces_output(_fn=None, *, verbose=True)[source]

Decorator for fns saving data to path, called as fn(data, path, **kwargs)

Can be used either as @produces_output or @produces_output(verbose=False).

The wrapped fn: - also accepts any Pathlike for path

  • raises MultipleSavesPerRunException if the same (resolved) path is written more than once in a run (by any wrapped fn), unless multiple_saves_per_run_ok=True

  • if check_outputs_unchanged (set by -c/-C CLI flags) and path exists, checks that the new output would not change it (not writing it, if unchanged). See ignore_output_change_check for how changes are handled.

Parameters:

  • _fn – the fn to wrap, when used without parentheses (@produces_output)

  • verbose (bool) – default for verbose kwarg of wrapped fn (whether to print path before writing)

Loads CSV of responses (e.g. ij_certain-roi_stats.csv), of odor X fly-ROI shape

Returns DataFrame with row index levels like [‘panel’, ‘is_pair’, ‘odor1’, ‘odor2’, ‘repeat’] (‘odor<N>’ levels after ‘odor1’ only for air-mixed components), and column levels flyroi_cols (‘date’ parsed to datetime, ‘fly_num’ to int). E.g.:

date 2024-09-03 fly_num 1 roi D DA1 DA2 panel odor1 odor2 repeat glomeruli_diagnostics 3mtp @ -5 solvent 0 -0.062 -0.025 -0.189

1 0.065 -0.003 -0.072

Parameters:

  • check_vs_pickle (bool) – if True, and a pickle with the same name (but ‘.p’ suffix) exists alongside CSV, checks loaded data matches it

  • warn_ (bool) – passed to drop_old_odor_index_levels, if called

  • verbose (bool) – if True, prints path and modification time of CSV (and result of any pickle check)
